# 日摘 · 2026-09-15

这是博客的第一份「日摘」：用表格回顾当天实际做了什么，而不是用脚本从正文里剪几句充数。

## 任务

| 项 | 内容 | 结果 |
|----|------|------|
| 建站 | 本地静态博客：首页、侧栏、文章列表 | 完成 |
| 内容结构 | 发布时间、标签、文末 AI 提炼（写在文头元数据） | 完成 |
| 约定 | 文件命名、`config.toml`、标签清单 | 完成 |
| 写作入口 | 本机网页编辑器（不暴露公网） | 完成 |
| 分类 | 标签页与标签归档 | 完成 |
| 版本管理 | 安装 Git 并 `git init` | 完成初始化；尚未推远程 |
| 上线 | GitHub Pages 工作流文件 | 已准备，等远程仓库 |
| 假提炼 | 浏览器里截断拼接「生成草稿」 | 已删除 |

## 进展

| 进展 | 说明 |
|------|------|
| 源码与产物分离 | 文章在 `posts/`，网页在 `site/`，构建可重复 |
| 命名统一 | 文章改为 `YYYY-MM-DD-...md` |
| 编辑体验 | 可在浏览器新建/编辑，保存后自动构建 |
| 日摘体例 | 本日这份日志即样例：表格 + `日摘` 标签 |

## 问题

| 问题 | 影响 | 处理 |
|------|------|------|
| 本机一度没有可用 Python / Git | 构建与版本管理卡住 | 手动安装后恢复 |
| Git 用包管理器下载失败 | 无法自动装 Git | 改手动安装 |
| 编辑器旧进程占着旧端口 | 改了代码页面仍像没更新 | 换端口并重启进程 |
| 截断脚本充当「AI」 | 摘要质量明显差一截 | 去掉按钮，改走真模型写日摘 |

## 反思

| 点 | 结论 |
|----|------|
| 便宜步骤 vs 贵步骤 | 生成 HTML 可以全本地、每次全量构建；归纳、提炼必须由模型在对话或定时助手里做 |
| 公网写作 | 本机编辑已经满足日常；外网可写要登录和服务器，先不做 |
| 日摘位置 | 不要塞进每篇文章的提炼框；单独发一篇日志，标签用 `日摘` |

无实质进展的日子可以不发，或只写一行「无记录」。
